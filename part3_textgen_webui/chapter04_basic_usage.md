# 第4章:基本操作とインターフェース

## 4.1 メイン画面の構成

```
画面レイアウト:
├── 左サイドバー: モード選択
├── 中央: メイン作業エリア
├── 右サイドバー: パラメータ
└── 上部タブ: Model, Parameters, Extensions等
```

## 4.2 チャットモード

### 基本的な使い方

```
1. "Chat" タブを選択
2. テキストボックスにメッセージ入力
3. "Generate" または Enter キー
4. 応答を待つ
```

### 便利な機能

```
✓ Continue: 生成を続行
✓ Regenerate: 再生成
✓ Remove last: 最後のメッセージ削除
✓ Copy: クリップボードにコピー
✓ Replace last reply: 応答を編集
```

## 4.3 ノートブックモード

### 長文執筆

```
用途:
- 小説・シナリオ
- 技術文書
- ブログ記事

操作:
1. "Notebook" タブ
2. テキストエリアに初期文章
3. "Generate" で続きを生成
4. "Continue" で更に続行
```

## 4.4 パラメータの基本

### 主要パラメータ

```python
# Temperature: 創造性
0.1-0.5  # 堅実、事実重視
0.7-0.9  # バランス
1.0-1.5  # 創造的

# Top-P: 多様性
0.9  # 標準
0.95 # やや多様

# Top-K: 候補数制限
40   # 標準
100  # 多様
```

## 4.5 プリセットの保存

```
1. パラメータを調整
2. "Parameters" タブ
3. "Save" ボタン
4. プリセット名を入力
5. 後で "Load" から呼び出し
```

## 4.6 会話の管理

### 保存と読み込み

```
保存:
"Chat" タブ → "Save history" → ファイル名入力

読み込み:
"Chat" タブ → "Load history" → ファイル選択
```
