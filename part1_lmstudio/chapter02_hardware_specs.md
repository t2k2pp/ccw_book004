# 第2章：ハードウェア仕様とシステム要件

## 2.1 AMD Ryzen AI Max+ 395詳細仕様

### 2.1.1 プロセッサアーキテクチャ

AMD Ryzen AI Max+ 395は、AMDの最新Zen5アーキテクチャをベースとした革新的なAPU（Accelerated Processing Unit）です。コードネーム「**Strix Halo**」として開発され、AI推論に最適化された設計となっています。

#### コア構成
```
アーキテクチャ: Zen5
コア数: 16コア
スレッド数: 32スレッド
ベースクロック: 2.9 GHz
ブーストクロック: 最大5.1 GHz
L2キャッシュ: 16MB（1MB × 16コア）
L3キャッシュ: 64MB（共有）
製造プロセス: 4nm（TSMC）
TDP: 45W〜55W（標準）、最大120W（cTDP設定時）
```

#### Zen5アーキテクチャの特徴

1. **AI命令セットの強化**
   - AVX-512命令サポート
   - VNNI（Vector Neural Network Instructions）
   - INT8/FP16高速演算

2. **IPC（命令実行数/クロック）向上**
   - Zen4比で約10-15%の性能向上
   - より効率的な分岐予測
   - 拡張されたマイクロオペレーション融合

3. **電力効率の改善**
   - 高度なパワーゲーティング
   - ダイナミックな周波数・電圧制御
   - アイドル時の消費電力削減

### 2.1.2 統合GPU仕様

**Radeon 8060S (RDNA 3.5)**

```
GPUアーキテクチャ: RDNA 3.5
コンピュートユニット(CU): 40基
ストリームプロセッサ: 2560個
レイトレーシングユニット: 40個
AIアクセラレータ: 80個
GPUクロック: 最大2.9 GHz
演算性能:
  - FP32: 約14.8 TFLOPS
  - FP16: 約29.6 TFLOPS
  - INT8: 約59.2 TOPS
グラフィックメモリ: システムメモリ共有（最大96GB割当可能）
```

#### RDNA 3.5の改良点

1. **AI Matrix演算ユニット**
   - INT8/INT4演算の高速化
   - LLM推論に最適化

2. **メモリアクセスの最適化**
   - より大きなL2キャッシュ（16MB）
   - Infinity Cache: 64MB
   - 効率的なメモリコントローラ

3. **ROCm 6.x完全対応**
   - LM Studioでのネイティブサポート
   - PyTorch、TensorFlow、ONNX Runtime対応
   - HIP（Heterogeneous-compute Interface for Portability）

### 2.1.3 NPU（Neural Processing Unit）

```
世代: 第2世代 XDNA

専用アクセラレータ: あり
サポートフレームワーク:
  - ONNX Runtime
```

#### NPUの役割

NPUは以下のようなタスクに特化しています：

1. **軽量AIタスク**
   - 音声認識

   - 画像分類
   - オブジェクト検出

2. **省電力推論**
   - バックグラウンドAIタスク

   - CPU/GPUの負荷軽減

**注意**: 現時点（2025年）のLM Studioは主にGPUを使用します。NPUサポートは将来のバージョンで実装予定です。

### 2.1.4 メモリサブシステム

Ryzen AI Max+ 395の最大の特徴が、この強力なメモリサブシステムです。

#### メモリ仕様

- データコピー不要（ゼロコピー動作）
- CPU-GPU間の転送オーバーヘッドゼロ
- 柔軟なメモリ配分

**AMD Variable Graphics Memory:**
- 動的にVRAM割り当て量を調整可能
- 最大96GBまでGPU専用として割り当て可能
- システムメモリとのバランス調整が可能

```
合計使用: 61GB
利用可能残り: 67GB
```

## 2.4 性能予測とベンチマーク

### 2.4.1 理論性能

#### トークン生成速度の計算

LLMの推論速度は主に以下の要素で決まります：
1. メモリ帯域幅
2. 演算性能
3. モデルサイズと量子化レベル

**簡易計算式:**
```
トークン/秒 ≈ メモリ帯域幅(GB/s) / (モデルサイズ(GB) × 2)
```

#### Ryzen AI Max+ 395の理論値

```
メモリ帯域幅: 212 GB/s（実測）

7B Q4モデル（4.4GB）:
理論値 = 212 / (4.4 × 2) = 約24トークン/秒

13B Q4モデル（7.9GB）:
理論値 = 212 / (7.9 × 2) = 約13トークン/秒

34B Q4モデル（20GB）:
理論値 = 212 / (20 × 2) = 約5.3トークン/秒

70B Q4モデル（40GB）:
理論値 = 212 / (40 × 2) = 約2.7トークン/秒
```

**注**: これは理論的な最大値です。実際の速度はGPU演算性能、LM Studioの最適化、システムオーバーヘッド等で変動します。

### 2.4.2 実測性能の予想

実際の使用では、理論値の70-85%程度の性能が期待できます。

#### 予想トークン生成速度

| モデル | 量子化 | サイズ | 予想速度（t/s） | 用途 |
|--------|--------|--------|----------------|------|
| Qwen2.5 7B | Q4_K_M | 4.4GB | 17-20 | 高速チャット |
| Qwen2.5 14B | Q4_K_M | 8.4GB | 10-12 | バランス型 |
| Qwen2.5 32B | Q4_K_M | 19GB | 4-5 | 高品質対話 |
| Llama 3.1 70B | Q4_K_M | 40GB | 2-2.5 | 最高品質 |
| DeepSeek-V3 | Q4_K_M | 22GB | 4-5 | コーディング |

**💡 TIP**: 実用上、2トークン/秒以上あれば快適に使用できます。MS-S1 Maxなら70Bモデルでも実用的な速度で動作します。
